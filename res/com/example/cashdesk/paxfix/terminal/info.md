# INPAS PAX Fix (slip bridge)

Все операции без изменений передаются штатному INPAS. Обёртка не запускает
DualConnector, не читает его файлы и не меняет обработку оплаты или таймаутов.

После возврата из штатного драйвера в оперативной памяти регистрируются только
хеши банковских слипов. По хешу RRElectro PAX Fix применяет заданную ширину и
протяжку только к конкретному слипу этой операции.
