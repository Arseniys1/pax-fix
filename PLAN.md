# План до запуска на реальной кассе

## P0 — блокеры (код, без них нельзя)

1. **[сделано 0.3.1] Убрать статическую рефлексию** в `RRElectroPaxFix`
   `private static final Field DRIVER_FIELD = findDriverField();` → ленивый поиск
   внутри `print()`, `catch (Throwable)`, при неудаче — `super.print(...)`.
   Файл: `src/com/example/cashdesk/paxfix/kkm/RRElectroPaxFix.java`.
   Готово когда: переименование/отсутствие поля `driver` не мешает старту и печати.

2. **[сделано 0.3.1] Проверить запуск `.bat` при пути с пробелами**
   `prepareWindowsBatch()` оборачивает в `cmd /d /s /c`; реальный путь
   `C:\Program Files (x86)\INPAS\DualConnector` с пробелами, тест этого не покрывает.
   Проверить сценарий «есть только `DCConsole.bat`»; при провале — не оборачивать,
   запускать как штатный INPAS.
   Файл: `src/com/example/cashdesk/paxfix/terminal/InpasPaxFix.java`.
   Готово когда: `checkConnection` и `payment` проходят на реальной машине.

3. **[сделано 0.3.1] Вынести константы в параметры устройства**
   `WIDTH = 48`, `FEED_LINES = 15` → `connectionParameters()` (дефолты 48/15),
   без пересборки под другую ленту/шрифт.
   Файлы: `RrPrintExecutor.java`, `RRElectroPaxFix.java`.

## P1 — проверки на реальном железе

4. Слип на РР-01Ф, 80 мм: 48 колонок, суммы по правому краю, нет переносов,
   отрезка после текста, шапка/подвал, QR фискального чека не затронут.
5. Цикл терминала: оплата, возврат, отмена, сверка, отчёт, закрытие смены.
6. Таймаут: подвесить/отключить терминал. Проверить сообщение, отсутствие
   зависания, зафиксировать регламент «не повторять оплату до сверки».
7. Повторная печать слипа из истории: либо реестр на 2 использования/дольше TTL,
   либо осознанно принять 32 колонки для копий.

## P2 — выкатка на одну кассу

8. Сборка и установка плагина на одну кассу,
   бэкап, проверенный откат (удалить jar / вернуть штатные драйверы).
9. Наблюдение 2–3 дня: `launcher.log` (нет `DELETE PLUGIN`), `desktop.log`
   (ошибки печати/INPAS), сверка итогов по терминалу.

## Definition of done

P0 закрыты, тесты зелёные, пункты 4–6 пройдены на реальной кассе, откат проверен.
